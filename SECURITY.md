# Security policy

Report a suspected vulnerability through [GitHub private vulnerability reporting](https://github.com/HiveMagnus/proser/security/advisories/new).
Include the affected version, conditions, and expected impact. Redact
credentials, account identifiers, and manuscript content. Use a synthetic
fixture for any supporting material.

Keep production environment files, account data, manuscript bytes, and
authenticated browser artifacts out of public issues and pull requests.
