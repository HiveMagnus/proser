# October 31, 2026 security remediation

This pass updates Factory, Author and the maintained Word codec. It preserves
canonical Factory authority, Author authentication/proxy separation, manuscript
and review histories, existing acceptance assertions and the selected practical
release gate. No database schema or migration changes are included.

[Zod advisory](https://github.com/advisories/GHSA-mrhx-c7xc-m3w5),
[body-parser advisory](https://github.com/advisories/GHSA-27r3-jxmh-p828),
[deepmerge advisory](https://github.com/advisories/GHSA-gcqx-w48m-w2h4).
Other exact advisories are available from the package-manager audit metadata.
No advisory is ignored and no dependency is downgraded to evade an audit.

Zod's major upgrade uses its patched implementation, not the retained vulnerable
`zod/v3` compatibility entry. Record schemas declare string keys. Required fields
retain their separate missing/type errors; environment defaults use `prefault`
so numeric and boolean transformations still execute. The codec becomes
`1.0.0-proser.4` and its source/build/tarball/dependency ledger is regenerated.
Original upstream snapshots and their historical lock/license records remain
unchanged. Native DOCX exchange and publication corpus checks remain required.

Upstream deepmerge 4.3.1 has no published patch. The local backport preserves the
original bundled source, MIT license, declarations, registry integrity and source
hash under `ProserFactory/vendor/deepmerge`. Its writes now use own data
properties for both target and source keys, preventing the `__proto__` setter
from changing a result's prototype. Tests reproduce poisoning against the exact
retained original and prove the patched behavior for target and null-prototype
source cases, cloning, symbols and custom hooks. Another test verifies that
Jest resolves the maintained implementation. The native deploy includes the
local dependency directory so frozen installations remain reproducible.

## Gates and evidence

The root audit and Factory/Author CI audit steps include development tools;
Factory CI additionally audits the independently locked codec. There is no
exception list. The independent locks and package-manager boundaries remain.

Before this pass, the full audits reported Factory 46 vulnerable packages,
Author 28 advisory findings and the codec one high-severity finding. The earlier
CI-efficiency pass reported narrower production-only results; these totals have
different scopes and are not directly comparable. After remediation, all three
full package-manager audits report zero known vulnerabilities.

New regression cases cover early rejection before visiting oversized collection
elements, missing/type error compatibility, compressed JSON with trailing bytes
in a separate process, and the local merge backport. Existing coverage thresholds
and browser repetitions are retained. A clean-cache production installation loaded
the patched codec and native SQLite successfully.

The release record separately captures final test counts, installed revisions,
health, worker readiness, authenticated disposable authoring/publication canary,
and hosted CI status. Physical-device/screen-reader certification and Microsoft
Word acceptance retain their existing explicit limits. Dependency advisories can
change after this dated audit snapshot.

Local release gates passed formatting, lint, typecheck, build and full audits.
Factory passed 144 suites / 957 tests with coverage enabled; Author passed 850
tests with Turbo reuse disabled. Additional gates passed 36 codec, 129 smoke,
42 CLI, 7 local merge-backport and 20 CI-policy tests. Exact ledger generation,
Canvas/browser repetitions and independent native document validators remain
part of the recorded candidate evidence.
