# Canvas release record

Proser V1 includes the structured Canvas writing surface for desktop and mobile.
Factory owns the manuscript and its structured revisions. Author proxies
authenticated API calls and retains in-progress operations by user and book.

The release includes bounded passage editing, exact receipt recovery, tracked
revisions, and document import and publication. Revision campaign acceptance
uses the [practical browser gate](CANVAS_R2_ACCEPTANCE.md). Device and
screen-reader certification remain incomplete. Reference-profile performance
certification and Microsoft Word application acceptance remain open.

See [Compose setup](docs/COMPOSE.md) for deployment, [Canvas maintenance](ProserAuthor/docs/CANVAS_MAINTENANCE.md)
for dependency provenance, and the [backlog](CANVAS_NEXT_RELEASE_BACKLOG.md)
for remaining work.
